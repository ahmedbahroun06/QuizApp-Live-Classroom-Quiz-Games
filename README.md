# QuizApp - Live Classroom Quiz Platform

A fast, lightweight quiz platform for teachers and students.
Teachers create quizzes and generate game PINs. Students join instantly with no account needed.

## Live Demo

https://app-2d8d890e-b275-4f97-a12e-6f00ad517986.cleverapps.io/


## Features

- Secure teacher registration and login
- Create and manage quizzes and questions
- Generate unique game PINs per session
- Students join via PIN and nickname, with no signup
- Live leaderboard and real-time scoring
- Full relational database schema for users, quizzes, questions, answers, sessions, and scores

## Tech Stack

PHP, MySQL, HTML, CSS, JavaScript

## Getting Started

1. Clone the repository and set up a local server with XAMPP or WAMP.
2. Import the database schema from `database.sql`.
3. Configure your database credentials in `config.php`.
4. Open `index.html` in your browser.
